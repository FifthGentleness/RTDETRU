【 Part 0 】 原版 RT-DETR-R18vd 参考结构（所有改进的对比基准）
--------------------------------------------------------------------------------
配置: rtdetr_r18vd_6x_visdrone.yml (backbone=PResNet, encoder=HybridEncoder)

Backbone PResNet-r18vd (return_idx=[1,2,3]):
  输入 [B,3,640,640]
  ├─ Stem(d变体): Conv(3→32,s2)→[B,32,320,320] → Conv(32→32)→[B,32,320,320]
  │              → Conv(32→64)→[B,64,320,320] → MaxPool(s2)→[B,64,160,160]
  ├─ Stage1 (P2/4):  2×BasicBlock          → [B,64,160,160]   (不输出)
  ├─ Stage2 (P3/8):  2×BasicBlock          → [B,128,80,80]    ← proj_feats[0]
  ├─ Stage3 (P4/16): 2×BasicBlock          → [B,256,40,40]    ← proj_feats[1]
  └─ Stage4 (P5/32): 2×BasicBlock          → [B,512,20,20]    ← proj_feats[2]
  BasicBlock: x → branch2a(3x3+BN+ReLU) → branch2b(3x3+BN) → (+shortcut) → ReLU

HybridEncoder (hidden_dim=256, expansion=0.5):
  input_proj: P3/P4/P5 各自 Conv1x1+BN → 256通道
    P3: [B,128,80,80]→[B,256,80,80];  P4: [B,256,40,40]→[B,256,40,40];
    P5: [B,512,20,20]→[B,256,20,20]
  AIFI(仅P5, 1层): flatten 400 token → MHSA(8头) + FFN(1024) → [B,256,20,20]
  FPN(自顶向下):
    y5 = lateral1x1(P5')→[B,256,20,20] → up→[B,256,40,40]
    cat[y5up, P4'] = [B,512,40,40] → CSPRepLayer(512→256) → p4_inner
    y4 = lateral1x1(p4_inner) → [B,256,40,40] → up→[B,256,80,80]
    cat[y4up, P3'] = [B,512,80,80] → CSPRepLayer(512→256) → f3 [B,256,80,80]
  PAN(自底向上):
    ds(f3)=Conv3x3s2 → [B,256,40,40]; cat[ds,y4]→CSPRep→ f4 [B,256,40,40]
    ds(f4)=Conv3x3s2 → [B,256,20,20]; cat[ds,y5]→CSPRep→ f5 [B,256,20,20]
  输出: f3/f4/f5 = [B,256,80/40/20,80/40/20] → RTDETRTransformer

Decoder RTDETRTransformer: 3层decoder(VISDRONE配置), 300 queries, num_denoising=100

◆ 8. rtdetr_r18vd_6x_visdrone_dsadcc.yml —— DSADCC v1
  ★ backbone = PResNet_DSADCC（DSA_v2 + DCC 双分支）
  插入位置: stage2/stage3（即 P3/P4 所在 stage，索引[1,2]）最后一个 BasicBlock，
           在 branch2b 之后、残差相加之前串联 DSADCC 模块。
  BasicBlock 数据流(以stage2, ch=128为例, reduction=4 → Cr=32):
    x [B,128,80,80] → branch2a → branch2b → [B,128,80,80] → DSADCC → [B,128,80,80]
    → (+x) → ReLU

  DSADCC 结构图 (输入x [B,C,H,W], C=128, Cr=C/4=32):
    x ──┬─→ channel_reduce(1x1) → xs [B,32,80,80] ─┬────────────────→ DCC分支
        │                                            │
        │   【DSA_v2分支: 多尺度空间聚合】            │   【DCC分支: 通道校准】
        │   xs → DW3x3 ─→ f1 [B,32,80,80] ─┐        │   xs → GAP → favg [B,32,1,1]
        │   xs → DW5x5 ─→ f2 ──────────────┤        │   xs → GMP → fmax [B,32,1,1]
        │   xs → DW7x7 ─→ f3 ──────────────┤        │   favg→FC(32→8)+ReLU → favg_r
        │   xs → DW3x3d2→ f4 ──────────────┤        │   fmax→FC(32→8)+ReLU → fmax_r
        │        cat[f1..f4] [B,128,80,80] │        │   cat[favg_r,fmax_r]→Conv1x1→softmax
        │        → GAP → Conv1x1 → softmax │        │   → 标量α,β [B,1,1,1]
        │        → 全局权重 w1..w4 [B,4,1,1]│        │   α·favg_r+β·fmax_r → FC(8→32)+Sigmoid
        │        Σ wi·fi → fdsa [B,32,80,80]│        │   → Wc [B,32,1,1] → xs*Wc → fdcc [B,32,80,80]
        └──────────────────────────────────┴────────┘
                    cat[fdsa, fdcc] [B,64,80,80] → Conv1x1+BN+SiLU → out [B,128,80,80]
  ★ 与原版差异: 无Scharr边缘、无小波、无cross_gate；DSA权重为全局标量(GAP后生成)；
    DCC为标量α/β融合（强正则）。输出通道与原版BasicBlock一致。

◆ 9. rtdetr_r18vd_6x_visdrone_dsadcc_v2.yml —— DSADCC v2（过拟合版本）

    (b) DCC: ★逐通道α/β（reshape [B,2,Cr,1,1]后softmax，每通道独立决定avg/max混合）

◆ 10. rtdetr_r18vd_6x_visdrone_dsadcc_v3.yml —— DSADCC v3
  插入位置同v1/v2（stage[1,2]末block, branch2b后）。
  ★ v3相对v2的改动:
    (a) 共享channel_reduce（DSA/DCC共用一个降维，保证同特征空间）
    (b) DSA权重改回★空间自适应 [B,4,H,W]（逐像素权重, 而非全局标量）
    (c) DCC恢复★标量α/β（避免逐通道过拟合）
    (d) ★新增cross_gate交叉交互: GAP(fdsa)+Wc → cat → Conv1x1+Sigmoid → [B,2Cr,1,1]
        通道级校准权重，调制cat后的融合特征
  数据流(以ch=128, Cr=32为例):
    x [B,128,80,80]
    ├→ channel_reduce(1x1) → xs [B,32,80,80] (共享)
    │    ├─ DSA: DW3/5/7/3d4 → cat [B,128,80,80] → Conv1x1 → softmax
    │    │       → 空间权重 [B,4,80,80] → Σ wi·fi → channel_mix(1x1) → fdsa [B,32,80,80]
    │    └─ DCC: GAP/GMP→FC(32→8)→标量α/β→混合→FC(8→32)+Sigmoid→Wc
    │            → xs*Wc → fdcc [B,32,80,80]
    ├→ cross_gate: cat[GAP(fdsa), Wc] [B,64,1,1] → Conv1x1+Sigmoid → cw [B,64,1,1]

◆ 11. rtdetr_r18vd_6x_visdrone_dsadcc_v4.yml —— DSADCC v4
  插入位置同v3。★ v4相对v3的改动 = DSA加Scharr边缘分支(5路) + DCC改小波域校准+FiLM:
    x [B,128,80,80] → channel_reduce → xs [B,32,80,80]
    ├─ DSA(5路): DW3/5/7/3d4 + ★ScharrEdge(固定梯度核, 输出减均值去正偏置)
    │   → cat [B,160,80,80] → Conv1x1 → softmax → [B,5,80,80] → Σ → channel_mix → fdsa

        GAP/GMP/GAP(ll) → cat [B,96,1,1] → Conv1x1 → softmax → α,β,γ
        → global_feat = α·favg+β·fmax+γ·gap(ll) [B,32,1,1]
