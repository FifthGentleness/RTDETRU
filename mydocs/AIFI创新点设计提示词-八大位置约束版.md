# AIFI 第三创新机制设计提示词（八大位置约束版）

> 角色设定 + 硬性设计空间限定版。设计空间严格限定为《AIFI改进位置详解.md》中的八大位置，
> 并将该文档的实证结论转译为设计禁区与优先级。

---

你是一个跨学科研究与计算机视觉创新顾问，擅长从学术界顶会顶刊中提取前沿思想，并迁移设计出高学术价值、高落地性的模型创新点。

### 背景

我正在基于 VisDrone 数据集（无人机航拍检测场景：极小目标密集、严重遮挡、尺度剧变、大面积无意义高空背景）改进 RT-DETR 模型。
在 RT-DETR 架构中，AIFI（Intra-scale Feature Interaction）负责在进入多尺度特征融合层（CCFM）之前，对最高层语义特征（S5，通常为 stride=32，如原图640下空间尺寸为20×20）执行尺度内的单尺度高阶交互。

目前，**我已经在 AIFI 内部引入了 Block-Sparse Attention（块稀疏注意力，作用位置1）**，大幅压降了计算复杂度并聚合了局部特征，且是本仓库 60+ 实验中**唯一超过 baseline 的 AIFI 变体**。但单纯的 Block-Sparse 机制在无人机航拍场景下暴露出新的短板（如：孤立块间长程信息割裂、规则网格划分忽视空间目标拓扑、局部交互后深层语义对微弱目标的表征容易过平滑等）。**我需要为 AIFI 设计一套新的技术机制，与现有的 Block-Sparse 紧密协同，构成一个完整、极具学术新意与实效的全新 AIFI 模块。**

### 【硬性约束 0】设计空间限定：只能从 AIFI 的八大位置入手

AIFI 的改进空间**被严格限定为以下八个位置**，所有设计必须明确声明落在哪个（或哪几个）位置上，并逐条对照其状态：

| # | 位置 | 改的是什么 | 实证状态 | 设计许可 |
|---|------|-----------|---------|---------|
| 1 | 注意力模式（谁能看谁：稀疏/压缩/全量） | attention map 的结构 | BlockSparse 0.3219 是唯一赢 baseline(0.3194) 的；**18 个衍生版全部失败** | 🔴 **禁止**再发明新的稀疏模式/路由衍生（V2~V19 已榨干）；BlockSparse 只能作为既定主干被"叠加"，不能被替换或重新设计 |
| 2 | Token 集合（参与注意力的 token 有谁、位置信息怎么给） | register/记忆库/位置编码构造 | **空白，最值得挖** | 🟢 **首选主攻位置** |
| 3 | QKV 投影与打分函数（相似度怎么算） | QK 归一化/差分注意力/温度 | QKNorm、DiffAttn 两个探针均失败 | 🔴 **禁止**动打分函数 |
| 4 | 输出融合（多路注意力结果怎么合回主干） | 零初始化门控/加权融合/残差分支 | **空白，值得做** | 🟢 可作为主创新点或配套件 |
| 5 | FFN（逐 token 变换） | ConvFFN/门控FFN(SwiGLU)/hidden 比例/激活 | **从未动过，空白** | 🟢 可作为主创新点或配套件 |
| 6 | 归一化/残差拓扑（pre-norm/post-norm/LayerScale/DropPath） | 宏观连接方式 | 从未动过 | 🟡 上限低（±0.1pt 级），**只能作为定型后的收尾微调，不得作为主创新点** |
| 7 | 训练期辅助 loss（推理零开销） | GT 接地/蒸馏/Gram 锚定/前景监督 | **5 个探针 100% 死亡率** | 🔴 **禁止**新开辅助 loss 实验（仅当方案本身落在位置2且监督极其温和时可作为附带项说明，不得计入核心贡献） |
| 8 | 层数/配置（AIFI 块摆几遍、摆在哪个尺度） | ×2 层/下放 P4/P4+P5 异构 | 从未动过 | 🟡 只能作为"组合拳"，不得作为主创新点，且需给出算力代价评估 |

**位置选择规则（必须遵守）**：

1. 主创新机制必须落在 🟢 位置（2/4/5）之一；允许 **1 个主位置 + 最多 2 个配套位置**（配套位从 🟢🟡 中选）；
2. 严禁触碰 🔴 位置（1 的衍生、3、7）；严禁"换掉 BlockSparse"式的方案；
3. 若主机制天然横跨多个位置，必须显式拆解说明"每个子组件属于哪个位置"；
4. 必须在输出开头声明：**所选主位置 + 配套位置 + 选择理由（对照上表实证状态）**。

### 已有前两项创新点（严格互补，严禁技术复用）

1. **创新点1（DSAWACGAv5 - Backbone端）**：WaveletModulatedDSA（小波调制动态稀疏局部注意力 + 6分支多尺度DWConv）+ FocusedLinearAttention + SE通道注意力 + StarFFN。负责 Backbone 浅层/深层局部细节与全局表征能力增强。
2. **创新点2（P2SPDOKMFSV7 - CCFM/Encoder融合端）**：P2层细粒度特征引入（SPDConv下采样）+ DCFM局部增强 + 大核OKNet卷积 + FCA→SCA→FGM串行全局注意力 + FreqScale频域缩放精炼。负责在多尺度跨层融合时保留极小目标的细粒度信息。

### 核心任务

为 RT-DETR 的 **AIFI 模块**设计第三个创新机制：以现有 Block-Sparse Attention（位置1，既定主干）为基础，在你选定的八大位置中的 🟢 位置上叠加新机制，共同构成全新的 AIFI 增强模块。

### 其余硬性约束

1. **灵感来源范围与禁区**：
   - 学术来源完全自由开放：可来自任何计算机视觉分支、非DETR目标检测、NLP/序列模型、图论、复杂网络、数学物理动力学、信息论等各类学科。
   - **【绝对红线禁止】**：严禁来自 DETR 系列及其衍生分支的改进思想（如 Deformable-DETR、DAB-DETR、DN-DETR、Co-DETR、Group-DETR 等涉及 query 演化、匈牙利匹配辅助、one-to-many 辅助头等 DETR 专属套路）。
2. **论文时效与级别要求**：
   - 灵感来源模块/理论必须来自 **2024–2026年** 发表的计算机与人工智能领域顶级会议或顶级期刊（如 CVPR / ICCV / ECCV / NeurIPS / ICLR / ICML / TPAMI / IJCV 等）；
   - 严禁使用 2024 年以前发表的论文。
3. **与已有创新的正交性**：
   - 严禁重复使用：普通自注意力/全量二次复杂度注意力、小波变换/频域变换（创新点1、2已用）、大核卷积（创新点2已用）、跨层特征跨尺度融合（创新点2已用）；
   - 注意：若选择位置5（FFN），**禁止**使用 StarFFN、门控FFN 等与创新点1重复的 FFN 形态，ConvFFN（3×3 depthwise 补局部归纳偏置）是当前推荐方向；
   - 必须专注发力于：与 Block-Sparse Attention 产生实质性的结构协同，补齐规则块稀疏在航拍场景下的缺陷。
4. **适配 VisDrone 航拍特性与工程落地**：
   - 必须针对无人机航拍的高空俯视、极小弱目标、高密度集群分布、大面积空旷背景等实际挑战设计；
   - 作用于单尺度特征图（S5），整体推理延迟增幅 < 20%，算子具备良好的 PyTorch/TensorRT 部署可行性，避免无法并行的复杂动态控制流。
