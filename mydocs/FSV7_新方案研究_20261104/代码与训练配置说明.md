# SLGM / CIR / BQG-VFL 代码与训练配置

这三个方案分别在原始`rtdetr-r18-DSAWACGAv5-P2SPDOKMFSV7`上做独立改进。仅AIFI另提供BlockSparse可选版本；Decoder和损失配置整个模型均保持标准AIFI。四份配置都是完整YAML，不依赖继承或临时生成器。

## 配置与源码

配置目录：`ultralytics/cfg/models/rt-detr/`。下表省略共同前缀`rtdetr-r18-DSAWACGAv5-P2SPDOKMFSV7`。

|配置后缀|改动范围|主要源码|新增可训练参数|
|---|---|---|---:|
|`-AIFI-SLGM.yaml`|标准全局AIFI的注意力logit几何修正|`ultralytics/nn/extra_modules/aifi_slgm.py`|0|
|`-Decoder-CIR.yaml`|最后一层Decoder、P3、matching queries的插值读取|`ultralytics/nn/extra_modules/decoder_cir.py`|945|
|`-BQG-VFL.yaml`|最后一层matching分类VFL的整行梯度权重|`ultralytics/utils/loss_plugins/bqg_vfl_loss.py`|0|
|`-AIFI-BlockSparse-SLGM.yaml`（可选）|V1已有mask内的几何修正|`ultralytics/nn/extra_modules/aifi_slgm.py`|0，相对V1|

模块已注册到`extra_modules/__init__.py`、`tasks.py`和损失插件注册表。原基座YAML、原AIFI/Decoder/VFL实现及`train.py`保持不变。BQG配置在模型初始化时提前创建criterion，使其EMA统计能在设备迁移及ModelEMA创建前注册为模型buffer。

## 参数与启用方式

**SLGM**：配置第10层为`AIFI_SLGM, [1024, 8, 0.25, 30, 0.1, 0.000001]`，依次为FFN宽度、头数、最大η、渐进启用轮数、统计收缩系数和epsilon。保持标准AIFI的Q/K加位置编码、V与残差不加位置编码，保持全局400-token支持集。统计度量停止梯度，距离对Q/K保留梯度。

**可选BlockSparse-SLGM**：参数为`[1024, 8, 4, 4, 0.25, 30, 0.1, 0.000001]`，额外包含block_size和topk。保留V1的原始块均值路由、mask及位置编码路径；仍是稠密mask实现，没有承诺稀疏硬件加速。

**CIR**：最后一层head改为`RTDETRDecoderCIR, [nc, 256, 300, 4, 8, 3, 0.5, 30, 0]`，最后三个参数是最大κ、渐进启用轮数和层级索引（0=P3）。只在最后一个Decoder layer安装新cross-attention；通过末尾300个matching queries识别DN前缀，保留原self-attention和DN mask。原4个采样点不变，每点原有的4格点邻居按内容重加权。共享32→8投影和24→16→1 MLP，总计945参数。保留`align_corners=False`及虚拟零格点的边界语义。

**BQG-VFL**：`loss_name: bqg_vfl`，参数为`lambda_max: 0.25`、`warmup_epochs: 30`、`ema_momentum: 0.99`、`eps: 0.000001`。不修改IoU质量目标、匹配和回归项。只在最终matching分类计算额外权重；encoder/aux和DN走原路径。额外权重停止梯度，原VFL负类p²仍可导。DDP误差EMA按总误差/匹配数全局同步，空GT rank也参与同步；全空GT批次保留原FocalLoss fallback。

三个方向都由现有`RTDETRTrainer.preprocess_batch()`透传的真实epoch渐进启用：`max_strength × min(epoch / 30, 1)`。epoch是从0开始，界面第31轮达到满强度。不是按forward调用次数计数，验证不会推进调度。强度与BQG运行统计均为checkpoint中的buffer。

直接构造模块、不经过训练器时，默认强度为0；要检查启用后的行为需调用模块的`set_epoch(30, 350)`。将对应最大强度设0可做退化对照；将`warmup_epochs`设0则从一开始满强度。已训练权重推理沿用保存的强度，不会因为`eval()`自动改变。

## 训练命令

在仓库根目录、项目原有RTDETR环境中执行。下面仅给命令，未启动完整训练。沿用现有`train.py`的数据、640输入、batch4、350轮等设置。

```powershell
python train.py --model ultralytics/cfg/models/rt-detr/rtdetr-r18-DSAWACGAv5-P2SPDOKMFSV7-AIFI-SLGM.yaml --name rtdetr-r18-DSAWACGAv5-P2SPDOKMFSV7-AIFI-SLGM --device 0

python train.py --model ultralytics/cfg/models/rt-detr/rtdetr-r18-DSAWACGAv5-P2SPDOKMFSV7-Decoder-CIR.yaml --name rtdetr-r18-DSAWACGAv5-P2SPDOKMFSV7-Decoder-CIR --device 0

python train.py --model ultralytics/cfg/models/rt-detr/rtdetr-r18-DSAWACGAv5-P2SPDOKMFSV7-BQG-VFL.yaml --name rtdetr-r18-DSAWACGAv5-P2SPDOKMFSV7-BQG-VFL --device 0
```

可选AIFI分支：

```powershell
python train.py --model ultralytics/cfg/models/rt-detr/rtdetr-r18-DSAWACGAv5-P2SPDOKMFSV7-AIFI-BlockSparse-SLGM.yaml --name rtdetr-r18-DSAWACGAv5-P2SPDOKMFSV7-AIFI-BlockSparse-SLGM --device 0
```

主对照为原始FSV7、FSV7+AIFI-SLGM、FSV7+Decoder-CIR、FSV7+BQG-VFL。可选分支对照V1，不替代另外两个方向的原始基座。

## 验证

```powershell
python -B tools/verify_fsv7_proposals.py -v
```

验证脚本不依赖数据集、预训练权重或下载，不创建训练目录。CPU检查覆盖：

- 标准/PreNorm AIFI的零强度输出与输入梯度等价，V1可选分支的padding等价，以及启用后梯度有限。
- CIR零强度的双线性读值与坐标梯度、非方形图和零填充边界、内部常量保持、参数梯度、2/4维reference及DN隔离。
- BQG零强度整套loss/梯度等价；启用时仅最终matching分类改变；额外detached权重的整行梯度缩放；空GT fallback、验证期不更新统计、调度/状态保存。
- 四份完整配置的构造、128输入batch2训练前向/反向、推理形状、参数增量，以及BQG统计进入ModelEMA。

有CUDA时另检查新模块的AMP前向/反向，无CUDA则跳过该项。这些检查不代表完整训练收敛或AP改善；实际延迟和显存也应按训练/部署环境另测。

本机执行结果：**12项全部通过**，包括CUDA AMP检查。另逐个完成四份配置的GPU/FP32、640×640、batch1、满修正强度推理，输出均为`[1,300,14]`且全部有限。三份零参数增量配置各有17,612,100个可训练参数，CIR配置为17,613,045；未启动完整数据训练，也未生成新权重或训练结果目录。

## 来源与实现边界

- SLGM参考[LGA，ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/476ab8f369e489c04187ba84f68cfa68-Abstract-Conference.html)的query-specific几何度量，本实现用解析对角统计和限幅偏置。
- CIR参考[IART，CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/html/Xu_Enhancing_Video_Super-Resolution_via_Implicit_Resampling-based_Alignment_CVPR_2024_paper.html)的内容/坐标条件重采样，本实现保留四邻居双线性先验。
- BQG参考[Uncertainty Weighted Gradients，CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/html/Lin_Uncertainty_Weighted_Gradients_for_Model_Calibration_CVPR_2025_paper.html)，适配为sigmoid/IoU质量目标下的Brier式误差整行权重。

三者是研究报告中提出的检测适配，不是原论文模块的原样复现。
