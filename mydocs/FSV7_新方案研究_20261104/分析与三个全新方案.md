## 1. 结论与证据范围

建议的三个方向是：**AIFI 的query加权邻域几何度量校正；Decoder 的内容感知连续插值；保留 IoU 质量目标的 Brier 误差梯度重加权。** 对应来源分别是 ICLR 2026、CVPR 2024、CVPR 2025；均来自非 DETR 任务。以下缩写 SLGM、CIR、BQG-VFL 是本次适配方案的工作名，不是论文中的原模块名。

**按用户澄清修正基座约束：三个方案分别独立设计与验证，BlockSparse只允许作为AIFI方向的可选路线，不是三者共同的前提。** 定义B为原始`rtdetr-r18-DSAWACGAv5-P2SPDOKMFSV7`（标准AIFI、原Decoder、原损失），S为B将AIFI替换为BlockSparse V1的历史参照。

|方向|本次主方案的起点|BlockSparse关系|独立实验|
|---|---|---|---|
|AIFI-SLGM|B中的标准全局AIFI|不依赖；另可在S上做同机制可选适配|B+AIFI-SLGM，另可选S+AIFI-SLGM|
|Decoder-CIR|B中的原始Decoder|整个实验模型不引入BlockSparse|B+Decoder-CIR|
|BQG-VFL|B中的原始损失|整个实验模型不引入BlockSparse|B+BQG-VFL|

原报告把后续`S+CIR`、`S+BQG`及三模块组合列为默认计划，超出了用户对这三个独立方向的设定，现已移除。历史结果仍可与S比较作背景参照，但比较对象不等于方案基座。

全库发现 98 份 `results.csv`，其中 79 份属于目标基座；发现该前缀的 218 份 YAML。79 组日志按实验名称和结构归为 AIFI 47、Decoder 11、损失 18、融合 2、标准基座 1。这里只统计有日志的组数，不把“存在 YAML”算成“训练有效”。218 份配置逐项结构、79 组完整结果另附文件。

**只有 2 组跑到 350 轮，15 组达到至少 150 轮，39 组不足 50 轮。** 大量方法只能判为“当前短程轨迹不利”，不能判定其收敛上限失败。只有基座与 BlockSparse V1 目录保留 `args.yaml`。它们支持相同主要设置：640、batch 4、AdamW、初始学习率 1e-4、seed 0、deterministic=True、pretrained=False、AMP=False、350 轮。其余日志的完整启动参数与历史源码快照无法仅凭 CSV 恢复，不能擅自将落后归因于训练参数，也不能宣称所有对照已完全可复现。

## 2. 基座真正做了什么

虽然名称含 r18，当前 YAML 骨干实际是自定义 `Conv + C2f_DSAWACGA_v5`，不是原生 ResNet18。640 输入下的主要路径如下：

```text
P2: 128×160×160 ─ SPD 下采样 ─┐
P3: 256×80×80 ────────────────┼─ CCFFP2V7 → F3:256×80×80 ─┐
P4: 384×40×40 → 投影 ─┐      │                            │
P5: 384×20×20 → 256 → AIFI → Y5 → 上采样融合P4 → Y4 ─────┘
                                       F3下采样+Y4 → F4:256×40×40
                                       F4下采样+Y5 → F5:256×20×20
RTDETRDecoder([F3,F4,F5]): 300 queries / 3 layers / 8 heads / 每层级4采样点
```

关键解释：

1. `C2f_DSAWACGA_v5` 已有 1/3/5/7/9/11 深度卷积分支、可学习小波调制、聚焦线性注意力、SE、带局部 DW3/DW5 的 StarFFN。增加普通卷积门控、局部分支、通道注意力的功能重合度很高。初始化中的残差缩放也须按真实计算图检查。
2. AIFI 只作用于 P5 的 400 个 token、256 通道，FFN 维度 1024、8 头。它控制粗尺度语义交互，不能单独恢复 P5 已损失的小目标细节。
3. `CCFFP2V7` 把 P2 的 SPD 特征、P3、Y4 拼成 640 通道；约 160 通道走增强分支，480 通道保留 identity，再融合为 256。增强分支已有大核 DW31、DCFM、频率和空间/通道调制。V7 恢复 identity 是代码中明确记载的设计修正。
4. P2 被注入 P3 融合，**没有 stride=4 的独立检测输出头**。Decoder 实际读取 stride 8/16/32。小目标定位仍依赖 P3 的连续采样质量。
5. 标准 MSDeformAttn 的 offset、跨层级/采样点权重由 query 产生；每个采样点的 value 由 `grid_sample(..., mode='bilinear', padding_mode='zeros', align_corners=False)` 读取。这里存在一个与“query 之间如何交互”不同的改进入口。
6. 原分类目标是 detached IoU 质量分数，VFL 与 L1、GIoU 配套；默认 loss gain 为分类1、L1 5、GIoU 2，匹配代价为分类2、L1 5、GIoU 2。损失改进必须区分“匹配”“质量目标”“损失权重”“分类梯度”四个位置。

相关入口：`ultralytics/cfg/models/rt-detr/rtdetr-r18-DSAWACGAv5-P2SPDOKMFSV7.yaml`；`ultralytics/nn/extra_modules/dsawacga_v5.py`；`hybrid_encoder_p2_spd_okm_fs_v7.py`；`ultralytics/nn/modules/transformer.py:204`；`ultralytics/nn/modules/utils.py:42`；`ultralytics/models/utils/loss.py:87`；`ultralytics/utils/loss.py:135`。

数据约束也已实查：训练标签目录 6471 个 txt，按 class 0–9 的实例数依次为 79337、27059、10480、144866、24956、12875、4812、3246、5926、29647；最大/最小约44.6倍。最多一图902个标注，超过300个标注的图像12张。此统计来自当前标签，不等同于评估时可见目标数；它支持关注混淆与长尾，但不支持把“300 queries 不够”认定为全局主因。

V1 代码的“block_size=4”是**展平序列每4个 token一块**，不是4×4空间块。400 token共有100块，top4加自身块，因自身可能已在top4内，每行可见16或20 token，即4%–5%。路由来自原始特征块均值，所有头共享；最终仍计算稠密 QK 矩阵再 mask，**没有据此获得硬件稀疏加速**。标准 AIFI 只给 Q/K 加位置编码，而 V1 先把位置编码加进 src，V 和残差路径也随之改变；因此 V1 与标准基座的提升不能全部解释成稀疏屏蔽的效果。

## 4. 新方案一：AIFI-SLGM，基于标准AIFI的query加权几何度量

### 来源与迁移边界

**Local Geometry Attention for Time Series Forecasting under Realistic Corruptions，ICLR 2026 正式会议论文**，Dongbin Kim 等。原任务是时间序列预测及真实型噪声鲁棒性，非 DETR；核心是 query-specific 距离度量。正式出处：[ICLR论文页](https://proceedings.iclr.cc/paper_files/paper/2026/hash/476ab8f369e489c04187ba84f68cfa68-Abstract-Conference.html)，[论文PDF](https://proceedings.iclr.cc/paper_files/paper/2026/file/476ab8f369e489c04187ba84f68cfa68-Paper-Conference.pdf)，[作者实现](https://github.com/dongbeank/LGA)。

本方案借用“每个query根据局部数据几何调整度量”的原理，采用解析对角统计，**不是原论文学习度量网络与辅助训练的完整复现**，不继承其理论保证或时序实验增益。

### 精确定义

**主方案以B中的标准AIFI为起点，不引入BlockSparse。** 保留P5上的400个token、全局可见性、原QKV投影、输出投影、FFN和归一化。位置编码沿用标准AIFI：Q/K输入为`src+pos`，V输入和残差仍为`src`，不能搬用V1将pos加入V和残差的方式。令每头每query的键集合为S_i；主方案S_i包含全部400个键，原全局注意力为a⁰，头维d=32。“query加权邻域”指a⁰形成的软特征邻域，没有选块、top-k或稀疏mask。

```text
s_i,d = stopgrad[ Σ(j∈S_i) a⁰_ij (k_j,d − q_i,d)² ]
s'_i,d = s_i,d + 0.1 mean_d(s_i,d) + ε
g_i,d = clip(mean_d(s'_i,d) / s'_i,d, 0.25, 4)
g_i,d ← g_i,d / mean_d(g_i,d)
D²_ij = mean_d[ g_i,d (q_i,d − k_j,d)² ]
τ_i = stopgrad[ Σ(j∈S_i) a⁰_ij D²_ij ] + ε
S'_ij = S⁰_ij − η(t) clip(D²_ij / τ_i, 0, 4), j∈S_i
a' = softmax(S'); attention_output = W_O(concat_heads(a' V))
η(t) = 0.25 × min(t/30, 1)，t为epoch，可在[0,0.125,0.25]内消融。
```

统计路径 a⁰、g、τ detach，D 对当前 Q/K 保留梯度。修正幅度最多1个logit，不改变全局可见性。不新增参数和辅助loss；η=0时回到标准AIFI的注意力，后续残差、Norm和FFN也保持标准AIFI。这里“局部”指query加权的特征邻域，不等于图像空间邻近。

query加权距离统计较大的方向被适度减权，较小的方向在距离中更敏感。它是在全局候选中重分配注意力，不能把背景抑制视为已证事实。主方案没有router漏选问题，但大量背景也可能主导软邻域统计；稀有真实目标本身也可能是局部离群点，因此限幅和下述验证不可省。

**可选BlockSparse适配不是主方案前提。** 如果另行评估S+AIFI-SLGM，仅将S_i限制为V1已有可见集合，保留V1原路由、mask与位置编码路径，再使用masked softmax；η=0回到V1。此时只能调整选中边，不能找回router漏选。该实验只回答“AIFI改进能否叠加BlockSparse”，不改变Decoder和损失方向的基座。

避免构造 B×H×N×N×d 中间张量：可由 a⁰K²、a⁰K 计算 s；由 g(K²)^T、(q⊙g)K^T、Σgq² 计算 D。按稠密实现粗估新增约0.164G MAC/图（约0.328 GFLOP/图，MAC按2FLOP），尚未含小算子；零参数不等于零延迟，更不能宣称真稀疏加速。

### 与仓库差异、诊断和退出条件

- V5/QKNorm改向量归一化，V6用原特征块的均值/标准差**改变选块**，V19改router；这里在标准全局AIFI中，按头、按query改变**对角距离度量**，不需要选块。即使做可选稀疏适配，也只调整已有mask内分数。
- 已有正交残差方案是在输出更新方向上作分解，和这里的边分数度量不同。
- 必做对照：η=0；g恒为1的各向同性距离；完整g；温度/分数方差匹配的普通attention。观察对前景的注意力质量、头间差异、g离散度与裁剪占比。
- 若各向同性距离已经解释全部收益，不能将提升归因于局部几何；若度量大量饱和或小目标召回下降，应收缩η，而非继续增加router/全局分支。

## 5. 新方案二：Decoder-CIR，内容感知连续插值

### 来源与选择2024例外的理由

**Enhancing Video Super-Resolution via Implicit Resampling-based Alignment（IART），CVPR 2024**，Kai Xu 等，正式会议页：[CVF](https://openaccess.thecvf.com/content/CVPR2024/html/Xu_Enhancing_Video_Super-Resolution_via_Implicit_Resampling-based_Alignment_CVPR_2024_paper.html)，[作者论文全文](https://arxiv.org/html/2305.00163v2)。原任务为视频超分辨率，采用坐标表示和局部特征交互完成重采样，不是DETR。预印本编号始于2023，采用年份按正式CVPR 2024，符合本次允许的2024例外。

选择它是因为当前Decoder恰好把连续采样交给固定双线性插值；来源直接研究这个算子对高频信息的影响。其VSR结论不代表检测AP一定提高。本方案保留双线性先验，做轻量化适配，不引入光流、视频、多帧或原论文完整网络，也不宣称恢复已丢失的高频。

### 精确定义与安装位置

以原始基座B为起点，保留标准AIFI，整个模型不加入BlockSparse，也不预先叠加AIFI-SLGM。第一版只修改**最后一层Decoder、matching queries、P3层级的value读取**，保留self-attention、300 queries、原offset、原4采样点、参考框、跨层级/采样点权重、DN及匹配逻辑。其余层、P4/P5与DN维持原读取。

对原采样坐标 s，取双线性本来就涉及的4个格点 j。令 b_j(s) 为原双线性系数，v_j∈R³² 为每头value，q_h为cross-attention输入query的对应32维片段：

```text
δ_j = tanh(MLP([U q_h, V v_j, PE(s−p_j)]))
a_j = b_j(s) exp(κ(t)δ_j) / Σ_m b_m(s) exp(κ(t)δ_m)
v_read = Σ_j a_j v_j
κ(t) = 0.5 × min(t/30, 1)
```

U、V为32→8，PE用每坐标2个频率的sin/cos共8维，MLP为24→16→1；最后P3一个模块，跨头/采样点共享。含bias总参数 **945**。κ=0精确退化为双线性；MLP普通非零随机初始化，κ用外部调度逐步变大，避免两套可学习因子同时零初始化。

实现必须遵守 `x=s_x W−0.5, y=s_y H−0.5` 的 `align_corners=False` 语义；边界外保留虚拟零格点及其系数，而不是删掉后按有效格点归一化，否则κ=0不等价。保留坐标经 b、PE 的梯度。系数b为0的格点一直权重0，不需要对0取log。归一化使常量域内部的值保持不变；由于零padding，靠边常量场仍应复现原双线性边界行为。

该式是局部凸组合，不能输出超过四个邻居特征凸包的信息；在恰好整数格点、只有一个b非零时也不起作用。其目标是**减轻现有采样的内容无关混合**，不是声称具备任意超分辨率能力。

### 与仓库差异、计算成本和消融

- RGCSA等改变query交互；FSGSA门控输出；NDP等增加独立偏移采样点；本方案保持偏移点数，改变同一个点的4邻居插值权重。
- 已有Mip-Splatting方案在采样点周围额外取四角做均匀面积读，偏向平滑；本方案复用原双线性邻居，以query、内容与小数坐标条件化权重。二者不应混同。
- 本方案固定使用原始基座B，不使用BlockSparse路由或mask，上游AIFI也保持标准实现。独立增益比较B+CIR与B；S仅作历史性能背景，不是训练基座。
- 显式gather成本需要实测。仅新增 P3 邻域value张量按300×8×4×4×32计有1,228,800个数，FP32约4.92MB/图、batch4约19.66MB，尚不含MLP中间量与反向图；不能因945参数就忽略显存/延迟。
- 先测κ=0与grid_sample随机坐标、边界、非方形特征的一致性和坐标梯度；再测内容项、坐标项、完整项，以及只改P3/最后一层的必要性。观察半像素平移稳定性、采样读值的前景/背景差异、APs与严格IoU下AP。若只改善低阈值召回、AP75不改善，不足以支持定位质量叙事。

## 6. 新方案三：BQG-VFL，质量保持的Brier误差梯度重加权

### 来源与迁移边界

**Uncertainty Weighted Gradients for Model Calibration，CVPR 2025**，Jinxu Lin 等：[CVF正式论文页](https://openaccess.thecvf.com/content/CVPR2025/html/Lin_Uncertainty_Weighted_Gradients_for_Model_Calibration_CVPR_2025_paper.html)，[全文](https://arxiv.org/html/2503.22725v1)，[作者实现BSCE-GRA](https://github.com/Jinxu-Lin/BSCE-GRA)。原研究为分类校准，核心是在梯度层使用多类别Brier误差，区分权重本身的导数与想要的梯度缩放，非DETR来源。

本次不照搬softmax CE，也不将检测的sigmoid质量向量解释成总和为1的概率分布；以下u是**质量感知的Brier式误差代理**。分类校准变好不自动推出检测AP变好。

### 精确定义

以原始基座B为起点，标准AIFI和原Decoder保持不变，整个模型不加入BlockSparse，也不预先叠加AIFI-SLGM或CIR。只修改**最后一层matching分支的分类损失**。匹配成功query集合为M，类别为y_i，q_i为已有detached IoU，p_i,c=sigmoid(z_i,c)，C=10：

```text
u_i = (p_i,y_i − q_i)² + Σ(c≠y_i) p_i,c² / (C−1)
μ = EMA(训练批内匹配query的u均值)，momentum建议0.99，首批均值初始化
r_i = 1 + λ(t) clip(u_i/(μ+ε) − 1, −0.5, 1)
w_i = stopgrad[r_i / mean(i∈M)(r_i)]
λ(t) = 0.25 × min(t/30, 1)
L_cls = [Σ(i∈M) w_i ℓ_VFL,i + Σ(i∉M) ℓ_VFL,i] / 原有normalizer
```

ℓ_VFL,i是**整行C类原VFL的和**：原负类项αp²、正类质量q、BCE(z,q×onehot)全部保留。对附加w、u、EMA停止梯度，但原VFL内部p²的梯度保持原状。这样额外机制对整行分类梯度作可解释缩放，不产生ℓ×∂w/∂z的附加项。mean(w)=1只表示平均权重不变，**不表示总梯度范数被严格守恒**。

未匹配query额外权重恒1；encoder、aux、DN、L1/GIoU、Hungarian代价、质量目标完全保持原样；无GT批次保持原fallback路径。λ=0精确回到原损失。训练增加O(BQC)运算和一个EMA状态，推理无新增参数和计算。

### 与已有损失的区别及主要风险

- DSAW-v4根据GT尺度、IoU统计调节特定项；这里两个query即使GT尺度和IoU相同，只要其他类别的混淆不同，就得到不同的整行梯度权重。
- PEQVFL改变q；这里q不变。类别频率权重对同类别样本相同；这里是每query误差。已有分布鲁棒负样本budget方案聚合跨query负类；这里不改变未匹配负样本的聚合方式。
- 本方案固定使用原始基座B，不使用BlockSparse，也不改匹配。独立增益比较B+BQG与B；不再把与V1组合列为后续必做项。
- 困难噪声标注也会得到较大权重，故先只覆盖最后一层匹配query、限制幅度并逐步启用。u反映预测误差/混淆，不是严格的认知不确定性估计。
- 必做对照：恒1；只用真实类别残差；加入非真实类别残差；detached额外权重与可导额外权重。记录真实类/非真实类梯度比、IoU分桶下分数误差、误分类与背景高分框、AP/APs/AP75。不能用大量背景主导的总体ECE替代检测收益。

## 7. 查重结果与创新边界

本次查了218份同基座配置、对应源码、`othercode`、`mydocs`，包括`第三创新点方案库_100.md`及当天已存在的`FSV7_全量实验复盘_20261104`报告。后者已有**正交残差更新、Mip-Splatting面积读、分布鲁棒负类budget**，本次三个方向均避开。

精确词检索包括LGA全名、IART、implicit resampling、BSCE、Brier、Uncertainty Weighted Gradients、query-specific metric等，未找到已有候选方法；Mahalanobis命中只在Kalman追踪器的门控距离，不是AIFI实现。又按机制与V5/V6/V19、NDP、RGCSA、DSAW、PEQVFL、类频/alpha/gamma/label smoothing等逐项比较。这里的“未出现”指本次检查的仓库实现与已有方案，不等同于已经证明整个学术界首次提出这套公式。

三个独立方向分别研究：**粗尺度语义中的干扰边、细尺度读值中的背景混合、质量分类中的样本梯度分配**。这些是各自待验证的假设，不预设三模块同时存在，也不能先把“抗噪、小目标、校准”都当成已证收益。

## 8. 实验方案：三个方向分别独立验证

1. 主实验固定为四组：B、B+AIFI-SLGM、B+Decoder-CIR、B+BQG-VFL。三个改进模型分别只改变对应环节，其余保持B。AIFI方向另外可选比较S与S+AIFI-SLGM，但不要求必须做。Decoder和损失方向不安排S+CIR或S+BQG，也不把三模块组合作为本次任务前提。
2. 使用相同数据、640、batch4、优化器、增强、350轮预算及固定seed做初筛。50轮可排查崩溃和数值，但不以早期AP轻微落后直接淘汰；至少比较150轮同预算趋势，有价值方案跑满350。V1原最佳发生298轮，v4到309轮，过早终止会系统性偏向早熟方案。
3. 最终候选与其直接基线做至少3个相同seed集合的完整对照，报告均值、标准差和逐seed差值；best AP与最后20轮均值并列。相较0.246的单种子优势，随机波动是必须测量的量，当前数据无法估计它。
4. 现有CSV不含APs/APm/APl、AP75、分类别AP、每图延迟与显存，后续用同一验证器复评weights再补。不得从AP50或总AP反推出小目标AP提升；没有保存权重的实验只能保留CSV结论。
5. 记录模型参数、实际延迟与峰值显存；主AIFI方案是全局稠密注意力，可选V1适配仍是稠密mask实现，CIR有gather中间量。不能把低参数量直接写成实时性结论。

**优先级区分：**按问题切口和与现有仓库的差异，优先研究Decoder-CIR；按实现/验证成本，BQG-VFL最便宜，SLGM其次，CIR需要最仔细的算子边界验证。不预报AP涨幅。若最终只有某一单点在多seed下稳定提升，保留该点，不能为凑三个创新强行叠加。
