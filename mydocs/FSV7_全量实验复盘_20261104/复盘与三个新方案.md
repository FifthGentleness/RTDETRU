# FSV7 全量训练复盘与三个新方案

日期：2026-11-04。统计依据：当前工作区 results.csv；五组最新实验数据更新至当日约13:13。

## 范围与比较口径

- 当前找到218份同基座配置、79份训练日志（1份标准AIFI基座、78份变体）。按主要改动归类：47份AIFI、18份损失、11份Decoder、2份融合拓扑变体，另有1份基座。
- 比较主要使用mAP50–95，所有AP数值乘100，差距单位为百分点。
- 近期差距 = 新实验最后10个已完成epoch均值 − BlockSparse对应epoch区间均值。该差距不等于最终成绩预测。
- 79份中只有标准基座和BlockSparse两份达到350轮，15份（含两份基准）达到至少150轮。对短程实验只能作预算筛选，不能宣布机制已被证伪。
- AFFI-TWCBS与AIFI-CoPPEBS两份日志名未与当前配置名精确对应：疑似分别对应AIFI-TWCBS、AIFI-CoPEBS，未擅自补成已确认的结构映射。
- 当前YAML说明现有实现，不能单凭CSV还原某次训练所用代码版本。用户已确认训练参数一致；因此本文不再把超参差异作为这五组近期实验的解释。

## 需要保留和需要修正的经验

1. 标准AIFI基座最佳31.943%@265轮，BlockSparse最佳32.189%@298轮，收益只有0.246个百分点。没有多seed结果，不能把这份小增益直接当成普适结构定律。
2. BlockSparse V1的选择先验值得保留。V2、AgentAttentionV2、QKNorm、Neighborhood、MiTA、TGHBSA、RABSA等已有较长训练记录，未出现超过BlockSparse最佳的证据。短程V11/V18/V19等仍不能归为完整训练失败。
3. DSAW-v4最佳32.046%@309轮（当前315轮），最近10轮高于BlockSparse同轮均值0.079个百分点；最佳仍低于BlockSparse 0.143个百分点。它说明适度、分阶段、分类/回归解耦的监督干预值得研究，不能归纳成“损失函数全灭”。
4. DSAW-v7保留v4损失并继续改匹配，280轮最佳31.745%，最近10轮较BlockSparse同轮低0.478个百分点。当前证据不支持继续把损失、质量目标、匹配成本一起改变。
5. 基座已包含小波调制局部DSA、多尺度卷积、FocusedLinearAttention、SE、StarFFN；融合端有P2-SPD、DCFM、大核、FCA/SCA/FGM、FreqScale和恒等路径。继续添加相同职责的全局分支/局部卷积/频域模块很容易职责重叠，但冗余是结构推断，不是已测得的因果。
6. AIFI处于P5的20×20、256维token流，不具备凭空恢复P2小目标细节的能力。Decoder接收P3/P4/P5，改读取方式有机会作用到更细粒度证据。
7. 较长训练的RGCSAv2、CLDM，以及短程的FSGSA、NSQ、AGGQA、SGM、PCSSA显示：继续增强query之间交互缺乏正面证据。现有跨注意力仍是参考框控制的离散点双线性读取。
8. BlockSparse验证分类loss从100轮0.55429升至350轮0.57505，而GIoU从0.63812下降到0.60220，mAP仍有改善。它提示分类校准/泛化值得检查；不能仅用loss回升证明过拟合，更不能把一个操作点P>R直接等同于系统召回瓶颈。
9. 需要先排除实现失活再淘汰机制。V16存在外层gamma=0与局部分支末端零初始化BN的双零问题；类似“恒等起步”的标签不代表支路一定可训练。不要把这种实验直接当成局部注意力的有效负对照。
10. 当前BlockSparse仍构造完整N×N注意力矩阵，mask稀疏不等于硬件稀疏加速。推理开销应实测，不能按理论密度估算50倍提速。

## 新方案一：AIFI——稀疏注意力软正交残差

### 来源及查重

借鉴非DETR的Orthogonal Residual Update，论文《Revisiting Residual Connections: Orthogonal Updates for Stable and Efficient Deep Networks》，NeurIPS 2025。来源讨论残差更新中沿已有输入方向的重复强化，提出使用正交分量更新。

原文：https://proceedings.nips.cc/paper_files/paper/2025/hash/67c15da4a9340140c60783d9a175fd3f-Abstract-Conference.html
官方实现：https://github.com/BootsofLagrangian/ortho-residual

本方案是小数据检测场景的温和迁移，不是原论文完整架构复现。仓库已有OrthoNets的正交滤波池化和X-QID的正交初始化，都不同于运行时逐token残差方向分解。未发现下述计算形式的已有实现。

### 挂载与公式

主位置：AIFI输出融合/残差更新。保持BlockSparse V1的路由、mask、QKV、位置约定、FFN、LayerNorm。

令s为进入注意力残差相加的当前token流（沿用V1的content+pos约定），u=BlockSparseAttention(s)，均为[B,400,256]。逐token沿通道计算：

    parallel(s,u) = <s,u> / (||s||² + eps) * s
    u_soft = u - rho(t) * parallel(s,u)
    y = LN(s + u_soft)
    output = LN(y + FFN(y))

首版rho(t)=0.25*min(t/30,1)，从原基准渐进过渡到部分正交更新；0.25和30轮只是待验证的初始超参。原论文完全去除平行分量对应rho=1，本方案保留大部分该分量，避免直接抹掉类别置信度所需的幅度信息。

### 与失败方案的区别

- 与QHGate不同：修改向量方向分量，而非把整个head输出统一乘一个gate。
- 与DiffAttn不同：不学习第二张注意力图、不改QK相似度。
- 与全局桥不同：没有新token、记忆或全局信息回注。
- 与LayerScale不同：只抑制平行部分，保留正交部分；不是整体缩放。

### 成本、风险、验证

零新增可训练参数；计算为逐token通道内积、除法和逐元素运算，额外O(BNC)，不是额外N²注意力。

应先测原BlockSparse的平行更新能量比例||parallel||²/(||u||²+eps)及其前景/背景分布。若该比例很小，或前景特别依赖平行分量，则应降低优先级。正交分量不保证就是目标信息，也可能是噪声。

消融：rho=0基准；相同调度上限0.125/0.25/0.5；相同平均范数的整体缩放对照。首轮只改注意力残差，不同时改FFN残差。

## 新方案二：Decoder——局部采样足迹积分

### 来源及查重

借鉴非DETR的新视角合成工作《Mip-Splatting: Alias-free 3D Gaussian Splatting》，CVPR 2024，尤其是“像素代表有限面积、需要对采样足迹积分”的思想；不引入它的3D高斯场景表示或频域处理。

作者论文：https://arxiv.org/abs/2311.16493
CVPR官方资料：https://cvpr.thecvf.com/media/cvpr-2024/Slides/32147.pdf

这是从渲染采样迁移到特征读取的自研适配；原文没有证明它能提高VisDrone检测精度。仓库的NDP8是增加独立可学习点，DHCFFN是AIFI卷积偏移，二者不等于下述围绕每个原点共享权重的面积读取。

### 挂载与公式

首版仅作用于Decoder最后一层matching query的P3读取；P4/P5、DN、query选择、self-attention、bbox与score头、匹配及loss均保留。

原MSDeformAttn对第k个位置s_k读取F(s_k)。改为：

    delta_x = min(r / W3, kappa * reference_width)
    delta_y = min(r / H3, kappa * reference_height)
    area(s_k) = mean_{a,b in {-1,+1}} F(s_k + (a*delta_x,b*delta_y))
    v_k = (1-lambda(t))*F(s_k) + lambda(t)*area(s_k)
    cross_output = sum_k attention_weight_k * v_k

r初值0.5个P3特征格，kappa初值0.25；lambda(t)=0.25*min(t/30,1)。这些均是待消融的适配超参。四个角点共用原始点的注意力权重，不新增独立候选，不产生跨query混合。

### 为什么值得作为新方向

现有大量Decoder尝试在“query如何互相影响/如何选query”上变化。该方案直接检查：同一query的读取结果是否对亚格点位置过于敏感。若是，将单点证据变成小范围的面积证据，有机会稳定小目标的分类输入。

### 成本、风险、验证

首版零新增可训练参数。被修改的P3读取由1次中心采样变成中心+4角点，局部采样量5倍；仅改3层×3尺度中的一个，忽略DN且按每层每尺度同预算估算，matching部分总采样量约为原来的13/9。整网延迟增幅不能由这个比例直接推定，必须实测。

双线性插值在单个网格单元内部具有特殊性质：若中心和对称四角均留在同一单元，四角均值可与中心值相同。因此必须先统计实际非零校正比例，并测试0.5/1输入像素平移时的输出稳定性。不能在几乎无效的半径上直接启动350轮。

主要风险是平滑抹掉本来微弱的目标响应，尤其极小目标；限制足迹到参考框的一部分，并保留中心读取。边界与越界采样沿用基准约定，单独检查边界目标。

消融：原始点读取；仅P3最后一层足迹读取；相近采样预算的独立点扩容；半径/混合强度消融。观察AP_small、AR_small、平移敏感度、精度和实际延迟。

## 新方案三：损失——类别内负监督预算聚合VFL

### 来源及查重

借鉴非DETR的《Distributionally Robust Loss for Long-Tailed Multi-Label Image Classification》，ECCV 2024，其类别维聚合和负标签梯度约束思想。

原文：https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/04926.pdf

原文使用C-LSEP和NGC；这里不照搬跨样本正负配对排序，而将其“类别内联合控制负监督”原则迁移为VFL负项的非线性聚合。以下公式为本报告提出的适配，不是原论文公式，尚未在本仓库训练验证。

### 挂载与公式

保留原IoU软质量目标、VFL正项、L1/GIoU和Hungarian匹配。首版仅改最终层matching query的分类负项，encoder/辅助层/DN沿用原损失。

对类别c，负标签集合为N_c，原VFL逐项负损失：

    e_ic = alpha * p_ic^gamma * softplus(z_ic),  i in N_c
    S_c = sum_{i in N_c} e_ic
    B_c = tau * log(1 + sum_{i in N_c} expm1(e_ic/tau))
    N_c_new = (1-lambda(t))*S_c + lambda(t)*B_c
    L_cls_new = (sum positive VFL terms + sum_c N_c_new) / original_normalizer

建议首版tau=1，lambda(t)=0.25*min(t/30,1)，沿用基准所有外层归一化与增益。lambda=0精确退化基准；tau趋于无穷时B_c趋于S_c。一个类别没有负标签时B_c=0；没有正标签时仍保留负类监督。

聚合项对单个负损失的导数为：

    dB_c/de_ic = exp(e_ic/tau) / [1 + sum_j expm1(e_jc/tau)]

与统一降低alpha不同，它取决于同类其他负样本，属于query间耦合的负监督预算。大量容易负样本不再简单线性累积；相对较难负样本占有更大的梯度份额。原始VFL部分仍保留至少75%，降低虚警失控风险。

### 为什么与已有损失不同

- DSAW按尺度和训练质量给匹配正样本增益；本方案改同类负样本集合的聚合。
- X-FCW改类频正项权重及匹配；本方案不改类频、正项或匹配。
- X-NegG和X-VFLA是逐元素gamma/alpha；本方案是同类query之间的非线性耦合。
- PEQVFL/SizeQ/QClamp改质量目标；本方案保留IoU软目标。
- 不新增与检测目标并行的辅助任务。

### 成本、风险、验证

推理零开销。训练在[B,Q,C]上按类别做expm1/log归约，无两两Q²矩阵。实现必须处理大logit的数值稳定性，不能直接对极大e/tau求exp。

适用前提需要先测：负类梯度总量是否确实压过正类梯度，哪些类别最严重。P/R差距或验证cls loss回升只能提供线索，不能替代梯度诊断。主要风险是减弱重复框或难背景的压制，导致precision下降；应记录每类正/负梯度、重复检测率、AP_small及固定FP预算下的recall。

消融：原VFL；降低alpha且平均负梯度范数与本方案匹配；新聚合；tau与lambda强度消融。这样才能区分收益来自减少负梯度总量还是类别内联合聚合。

## 实验顺序和成功标准

1. 三个方案独立叠加在BlockSparse冠军基座上；不要第一轮三者一起上，也不同时叠DSAW-v4。
2. 先做诊断与前向/反向检查：AIFI平行能量、Decoder有效足迹校正与平移敏感度、Loss正负梯度比例。若对应病灶不存在，降低方案优先级。
3. 诊断通过后，低成本先试AIFI和Loss；Decoder采样方案先确认明显作用且延迟可接受。以上是实验投资顺序，不是成功概率排序。
4. 对明显落后的方案可在80–120轮进行预算筛选；对于同轮差距小、仍持续追近的方案，不因0.1–0.2个百分点差距提前判死，保留350轮比较。
5. 使用同一数据划分、训练预算和max_det；分别汇报best AP、最后20轮均值、AP_small、AR_small、每类AP、延迟。不要仅用验证集某个最佳epoch的小增益宣称获胜。
6. 先以超过32.189%作为单次探索目标；值得定型的方案再使用配对seed重复，比较均值与波动。可预先约定0.3个百分点为实用收益门槛，但它不是从当前日志估算出的统计显著性阈值。

## 结论边界

本次对当前仓库的配置、模块定义及候选计算形式做了查重，没有发现上述三种具体方案已有实现。不能由此证明它们在全部公开文献中从未出现，也不能保证“非DETR来源”自动构成论文创新。这里的新意是针对本基座失败经验作出的适配和可检验假设；最终需要消融、跨seed和相关工作比较支撑。本文仅生成分析文档与统计表，未修改模型或训练任务。
