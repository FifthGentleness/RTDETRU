# AIFI 的 8 个细节改进位置详解

> 基于 RT-DETR AIFI（`TransformerEncoderLayer`）结构 + 本仓库 60+ 实验的实证结果整理。

---

## 一、先看 AIFI 的数据流：8 个位置分别长在哪里

```
x (B,C,H,W)                          ← P5 特征图进入 AIFI
│
├─① flatten + 位置编码               ★位置2：Token集合（加什么token、位置编码怎么给）
│        │
│        ▼
│  src = content + pos   (B,N,C)
│        │
│        ▼
│  ┌─────────────────────────────┐
│  │  Attention 内部              │
│  │  ② QKV投影 & 打分函数        ★位置3：Q/K/V怎么算相似度
│  │  ③ 注意力模式                ★位置1：谁能看谁（稀疏/压缩/全量）
│  │  ④ 输出融合                  ★位置4：多路注意力结果怎么合
│  └─────────────────────────────┘
│        │
│        ▼
│  src = src + Dropout(Attn(src))     ★位置6：残差/norm拓扑（pre-norm or post-norm）
│  src = Norm1(src)
│        │
│        ▼
│  ⑤ FFN: Linear(C→4C)→GELU→Linear(4C→C)   ★位置5：逐token变换
│        │
│        ▼
│  src = src + Dropout(FFN(src))      ★位置6（续）：第二处残差
│  src = Norm2(src)
│        │
│        ▼
└─⑦ 训练期辅助 loss（不改前向，从任意位置挂出）  ★位置7
   ⑧ 层数×作用层配置（这张图本身画几遍、画在哪个尺度） ★位置8
```

一句话记忆：**1~4 在注意力里，5 在 FFN 里，6 是连接方式，7 是额外监督，8 是整块怎么摆。**

## 三、每个位置的细节展开

### 位置 1：注意力模式 —— "谁能看谁"

- **问题的本质**：AIFI 默认全量 MHSA，P5 有 N=400 个 token（20×20），全量是 N² 打分。改进 = 在"保持全局感受野"和"减少打分"之间找平衡。
- **三大流派**：
  1. **稀疏化**（BlockSparse）：把 token 分块，每个 query 块只 attend 自己块 + top-k 相关块。✅ 你唯一验证成功的路。
  2. **代理中继**（AgentAttention）：引入少量 agent token，token 先 attend agent、agent 再广播回来。
  3. **局部化**（Neighborhood/ContextCluster）：只看邻域/聚类。
- **实证教训**：BlockSparseV2~V19 的 18 个衍生版（改路由方式、改块大小、加各种门控）没有一个超过原版。"简单的 top-k 块路由"就是甜区，这个位置的边际收益已榨干。
- **剩余机会**：不再发明新的稀疏模式，而是把 BlockSparse 当作既定主干，去配合其他位置（→ RBS 方案、位置 4/5 的叠加）。

### 位置 2：Token 集合 —— "都有谁在场"

- **默认假设**：参与注意力的只有 400 个图像 token，位置编码是固定 2D sincos。这个假设可以被打破两次：
  1. **加入非图像 token**：
     - *Register*（ICLR 2024）：M 个无位置可学习 token，平等参与注意力，吸收全局信息、消解注意力 artifact。→ RegisterMemory
     - *检索记忆*（RAT 2024）：把历史 batch 的 token 特征存进 FIFO 队列，当前 token 检索 top-k 历史相似 token 做交叉注意力。→ RetrievalAugmented。这是**全网络唯一能跨图像传知识的机制**。
  2. **改位置信息本身**：sincos 是静态先验，可换成可学习 PE / RoPE / 条件化 PE；RetrievalAugmented 特意用"无位置内容特征"做匹配也是一种选择。
- **为什么潜力大**：位置 1 是在"同一批 token 内部省算力"，位置 2 是在"增加新的信息源"，机制上前者已证明收益有限（+0.25pt），后者还完全没被验证。
- **成本**：register 几乎免费；检索分支每 token 多一次 (N×M) 相似度。

### 位置 3：QKV/打分 —— "相似度怎么算"

- **能动的点**：Q/K 做 L2 归一化稳定 logits（QKNorm）；用两组头打分取差消噪（DiffAttn）；温度 τ 可学习；检索匹配用纯内容特征。
- **实证结论**：QKNorm 充分训练后 -0.5pt，DiffAttn 中止时差距大。打分函数的"修正型"改进不改变信息流结构，收益天花板低。
- **结论：放弃。** 唯一保留的残余价值是"位置 2 的检索匹配用什么特征打分"——那属于位置 2 的设计细节。

### 位置 4：输出融合 —— "多路结果怎么合"

- **默认形态**：单路注意力输出直接残差加回。一旦你有两条注意力路径（如主注意力 + 检索/寄存器/稀疏分支），合并方式就变成独立设计点：
  - **零初始化标量门控**：`out + gate·aux`，gate 初始 0 → 模型自己学用多少（仓库 warm-up 惯例）。RBS 里没用，是现成的叠加点。
  - **逐通道/逐头门控**：gate 从标量升级为 (C,) 或 (H,) 向量，表达力更强，仍是零初始化。
  - **加权残差**：辅助分支乘可学习残差系数（类比 DSAWACGA 的融合思想）。
- **为什么值得做**：与唯一胜出的 BlockSparse 完全正交，改动 10 行代码，风险极低；且位置 2 的所有方案（RM/RA）最终都要靠这里决定"辅助信息用多少"，是配套件。

### 位置 5：FFN —— "逐 token 变换"

- **默认形态**：Linear(C→4C) → GELU → Linear(4C→C)，纯逐点 MLP，没有任何空间感受。
- **改进抓手**：
  1. **ConvFFN**：在 hidden 层后插一个 3×3 depthwise conv —— 注意力负责全局、FFN 补局部归纳偏置，与块稀疏互补性最好。
  2. **门控 FFN**（SwiGLU/GEGLU）：hidden 分两半，一半做门。LLM 侧验证过的涨点项。
  3. 调 hidden 比例/换激活（低成本低成本微调）。
- **为什么值得做**：60+ 实验从未碰过；P5 的 400 token 上加 dwconv 的开销几乎为零。

### 位置 6：归一化/残差 —— "宏观拓扑"

- **默认形态**：post-norm（先残差后 norm）。所有模块都留了 `normalize_before` 开关但没人用过。
- **能动的点**：pre-norm（训练更稳）、层缩放（LayerScale，残差支路乘 γ）、DropPath（随机深度）。
- **定位**：这类改动在分类/检测里通常是 ±0.1pt 级别的稳定性工具，不是涨点主力。适合在最终方案定型后做"最后一公里"微调，不值得单独开实验。

### 位置 7：辅助监督 —— "额外 loss"

- **吸引点**：推理零开销、结构零改动，故事好写。
- **残酷实证**：ForegroundGuided（前景监督）、FoundationDistill（蒸馏）、SDLoss、TSL、SUAL(-B) 全部中止且落后。原因推测：辅助 loss 梯度和 DETR 匹配损失的梯度方向冲突，或正则过强压低了表征自由度。
- **残余机会**：RegisterMemory 的 GT 类别接地是"温和版"（只监督 16 个 token 的池化输出，不碰主路径），是最后的验证；若再失败，此位置永久关闭。

### 位置 8：层数/配置 —— "块怎么摆"

- **默认形态**：1 层 AIFI，只作用在 P5（20×20）。
- **能动的点**：
  1. **×2 层**：堆两层同结构，最朴素的加深，P5 上开销可接受。
  2. **下放 P4**：P4 是 40×40=1600 token，全量注意力贵 16 倍——但用 BlockSparse 就可行，小目标收益理论上更大。
  3. **P4+P5 异构双层**：P4 用 BlockSparse、P5 用 RBS 等。
- **定位**：不发明新机制，只重组已验证的机制，属于"组合拳"阶段的事。

## 四、决策总结：先做什么、不做什么

```
                    已验证有正收益？
                         │
        ┌────────────────┴────────────────┐
        ▼                                 ▼
   BlockSparse(位置1)                其他全部位置
   0.3194 → 0.3219                   目前 0 探针成功
        │                                 │
        ▼                                 ▼
  把它当新主干, 叠加:                除非机制全新(位置2),
  ┌──────────────────────────┐      否则不单独开实验
  │ ① 位置2: RM/RA/RBS  ← 主攻 │
  │ ② 位置4: 输出门控     ← 配套 │
  │ ③ 位置5: ConvFFN     ← 互补 │
  │ ④ 位置8: 加深/下放    ← 组合 │
  └──────────────────────────┘
```

| 行动 | 理由 | 预期 |
|------|------|------|
| 🟢 训 RBS（已建好） | 位置 1+2 融合，两个已验证/高潜力机制 | 冲 0.325+ |
| 🟢 训 RegisterMemory 纯版 | RBS 的消融对照，位置 7 grounding 的最后一搏 | 区分增益来源 |
| 🟢 RBS + 输出门控 / ConvFFN | 位置 4/5 与 BlockSparse 正交，改动小 | 低风险 +0.1~0.2 |
| 🟡 AIFI×2 或 P4 下放 BlockSparse | 位置 8 空白，纯重组 | 算力换精度 |
| 🔴 V20+ 稀疏衍生 / QKV 修正 / 新辅助 loss / decoder 侧 | 实证已判死刑 | 不投算力 |
